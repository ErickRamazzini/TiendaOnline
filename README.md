## Descripción

Este proyecto es la maquetación de la página principal de una tienda online, hecha con HTML y Bootstrap 5. Es solo diseño, no tiene funcionalidad real (los botones no hacen nada, es de práctica).

## Componentes de Bootstrap que usé

- **Header (encabezado fijo)**: con `sticky-top` para que se quede pegado arriba al hacer scroll, y `bg-dark` para la franja de color.
- **Carousel**: banner con 3 imágenes, con flechas para pasar de una a otra.
- **Grid system**: `container`, `row`, `col-sm-3` y `col-sm-9` para dividir categorías y productos, y `row-cols-1` / `row-cols-md-3` para que los productos se acomoden 1 por fila en celular y 3 por fila en pantallas grandes.
- **Cards**: para mostrar cada producto con su imagen, nombre y botón.
- **Botones**: `btn`, `btn-dark`, `btn-lg` para el botón del carrito y los de "Agregar al carrito".
- **Badge**: el número rojo que simula el contador de productos en el carrito.
- **List group**: para el menú de categorías.
- **Bootstrap Icons**: el ícono del carrito de compras.

## Cómo se ve

- Encabezado fijo arriba con el nombre de la tienda centrado y el carrito con contador
- Carousel con 3 imágenes
- Menú de categorías al lado izquierdo
- 6 productos con imagen, nombre y botón de "Agregar al carrito"
- La página se acomoda sola en el celular (responsive)
- Footer con mi nombre y carné
